# Product Overview

This is a modern portfolio website showcasing professional experience, education, and projects. The site features:

- **Personal Portfolio**: Professional showcase for Minh Ngo
- **Multi-page Application**: Home, About, Education, and dynamic Project Detail pages
- **Responsive Design**: Mobile-first approach with desktop optimization
- **Modern UI**: Dark theme with gradient backgrounds and blue accent colors
- **GitHub Pages Deployment**: Automated deployment via GitHub Actions

## Key Features

- Lightning-fast performance with Vite
- Fully responsive across all devices
- Project showcase with detailed views
- Professional navigation and footer
- Optimized for GitHub Pages hosting

## Target Audience

Potential employers, clients, and collaborators looking to understand professional background and technical capabilities.
