# Java Stream API Exercises - Open Source Contribution

## Overview
An educational Spring Boot project designed to teach Java Stream API through practical exercises. This open-source project provides a playground for developers to learn and master functional programming concepts in Java through 21 comprehensive exercises covering filtering, transformation, sorting, and data manipulation.

## My Contribution

### Restructuring for Better Learning Experience
I contributed to improving the project's structure to enhance the learning experience for students and educators by proposing and implementing a **two-branch architecture**:

#### **Main Branch** - Student Version
- Contains 21 exercises with empty method bodies
- Provides clear TODO comments for guidance
- Allows learners to practice without seeing solutions
- Encourages hands-on learning and problem-solving

#### **Solution Branch** - Reference Implementation
- Complete implementations for all 21 exercises
- Demonstrates best practices and various approaches
- Serves as a reference for self-learners
- Useful for educators to validate solutions

### Key Improvements Implemented

#### Test-Driven Development (TDD) Approach
- Comprehensive unit tests for all 21 exercises
- Tests validate correctness of implementations
- Enables learners to verify their solutions immediately
- Promotes TDD best practices

- Exercise methods in **ExerciseStreamApi.java**

#### Documentation Enhancement
- Updated README with contributor information

## Project Architecture

### Data Model
The project uses a realistic e-commerce data model:
- **Customer**: Represents customers with tier levels
- **Order**: Contains order information with delivery dates
- **Product**: Products with categories and prices

Relationships:
- Customers can place multiple orders
- Each order contains multiple products
- Pre-loaded sample data in H2 database

### Technology Stack
- **Java 11** - Programming language
- **Spring Boot 2.6.3** - Application framework
- **Spring Data JPA** - Data persistence
- **H2 Database** - In-memory database
- **Lombok** - Code generation and boilerplate reduction
- **Maven** - Dependency management
- **JUnit** - Unit testing framework

## Exercise Categories

The 21 exercises cover various Stream API operations:

### **Filtering Operations**
- Filter products by category and price
- Find orders containing specific product types
- Predicate chaining and BiPredicate usage
- Complex filtering with nested streams

### **Transformation Operations**
- Apply discounts to product prices
- Extract specific fields from objects
- Map collections to different types
- FlatMap for nested collections

### **Aggregation Operations**
- Calculate total order values
- Find minimum and maximum prices
- Average calculations
- Counting and summarization

### **Sorting and Limiting**
- Sort products by price
- Order customers by tier
- Limit result sets
- Skip elements

### **Advanced Stream Operations**
- Group products by category
- Partition orders by conditions
- Collect to different data structures (Map, Set, List)
- Custom collectors

### **Date Operations**
- Filter orders by date range
- Recent order queries
- Date-based transformations

## Learning Approach

### For Students
1. Fork the **main** branch
2. Implement exercises following TODO comments
3. Run unit tests to verify solutions
4. Compare with **solution** branch for learning

### For Educators
1. Use **main** branch for assignments
2. Reference **solution** branch for grading
3. Tests provide automatic validation
4. Can be extended with additional exercises

## Technical Highlights

### Functional Programming Concepts
- Lambda expressions
- Method references
- Predicate composition
- Function chaining
- Stream pipelines

### Stream API Features Covered
- **filter()** - Filtering elements
- **map()** - Transforming elements
- **flatMap()** - Flattening nested structures
- **reduce()** - Aggregation operations
- **collect()** - Terminal operations
- **sorted()** - Ordering elements
- **distinct()** - Removing duplicates
- **peek()** - Debugging streams
- **anyMatch()**, **allMatch()**, **noneMatch()** - Matching operations
- **findFirst()**, **findAny()** - Finding elements
- **groupingBy()**, **partitioningBy()** - Grouping operations

- Working with Lists, Sets, and Maps
- Converting between collection types
- Using Collectors utility class
- Custom collection strategies
