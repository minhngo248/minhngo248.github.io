# Regulatory Jobs Application

## Overview
A serverless web application that aggregates and displays medical device regulatory job postings specifically for the Île-de-France region. The application provides automated job scraping, a REST API for job management, and a modern React frontend for browsing opportunities.

## Architecture

The application follows a **serverless architecture** built entirely on AWS services:

### Backend - AWS SAM
Serverless Application Model (SAM) with Python runtime powers the backend:

#### **API Layer**
- RESTful API endpoints for job management
- API Gateway with API key authentication
- Lambda functions handling CRUD operations
- DynamoDB for data persistence

#### **Automated Job Scraping**
- Scheduled Lambda worker function
- Integrates with **Adzuna API** for job data
- Runs twice daily (7 AM and 7 PM)
- Automatically updates job database
- Filters for regulatory positions in Île-de-France

#### **Lambda Functions**
- **Get All Jobs**: Retrieves complete job listings
- **Get Job by ID**: Fetches individual job details
- **Put Job**: Creates or updates job entries
- **Delete Job**: Removes job postings
- **API Worker**: Scheduled scraper for automated data collection

### Frontend - React TypeScript
Modern single-page application built with:
- **React 19** with TypeScript for type safety
- **Vite** for fast development and optimized builds
- **Custom hooks** for job filtering and data management
- **API client** with error handling and authentication
- **Firebase Hosting** for deployment

### Infrastructure Components
- **AWS Lambda**: Serverless compute for API and worker functions
- **API Gateway**: REST API management and routing
- **DynamoDB**: NoSQL database with simple table structure
- **EventBridge**: Scheduled triggers for automated scraping
- **CloudWatch**: Logging and monitoring for all functions
