# All things that I know so far about AI

## Models
- Multi modal: generate text, pdf, video, image
- Uni modal: generate only text, or image
Example: 
Multi-modal: GPT5, Claude Sonnet 4.5
Uni-modal: gpt-o4-mini

## Prompt Engineering
### One-shot prompt
Example: As a Senior Java Developer, explain me what concurrency is

### Multi-shot prompt
Example: 
I have a front page for my portfolio:
- First, fix navigation with Home, About, Contact
- Then, fix the main components
- Last, fix the footer

### Chain-of-Thought
Example: 
I have a front page for my portfolio. After each step, let me validate and then proceed to the next step.
- First, fix navigation with Home, About, Contact
- Then, fix the main components
- Last, fix the footer

2 scenarios:
- Step 1 OK: OK, proceed to the next step
- Step 1 Not OK: Navigation is not yet responsive. Please fix.

### Add XML tag or Markdown tag
Example:
I have this error while building Spring project. Here is the error <error>ERROR HERE</error>
```java
// Code Java
```
